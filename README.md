## Premium、Standard、Global 三条线路怎么选

三条线路在同一个机房里跑的是不同回程，价格却完全一样，选错了体验差很多。

**Premium 面向中国大陆。** 洛杉矶 Premium 走三网 CMIN2；台湾 Premium 的电信方向走 CTGNet，移动和联通直连。这三款里，香港 Premium 的机房位置离大陆最近，10Mbps 不限流量，$24.99/年，是四个机房里性价比最直观的一档。缺点是 10Mbps 只有 1.25MB/s 左右，传大文件慢，日常建站、跑 API、挂监控完全够。

**Standard 只在洛杉矶有。** 三网走移动 CMI 直连回国，端口比同价位的 Premium 大一档：50Mbps 不限流量、100Mbps 配 1TB，价格还是 $24.99。国内访问不如 CMIN2 稳定，带宽却翻了一倍多。预算固定、又想要速度的，这一档值得考虑。

**Global 是国际线路，带宽最大。** 洛杉矶 Global 三网双程走国际线路（cogent 方向），国内访问要绕路；台湾 Global 的电信、联通回程绕国际，移动回程走 CMI 直连。好处是同样的钱能拿到 100Mbps 不限流量或者 200Mbps 配 1TB，四个机房里带宽最高的两款都在这里。访客在海外、或者主要用途是国际流量转发，选它。

## 买之前必须知道的六件事

**1. 特价年付不支持升级配置。** 1 核 1GB 用着不够，只能重新买一台，不能在这台上加内存加硬盘。常规月付的弹性云可以随时升级，降级要联系客服；$24.99 这批不在此列。如果你预计三个月后流量会涨，一开始就别买年付。

**2. 特价年付不支持退款。** LightLayer 没有公开的退款政策，$24.99 年付明确不退款，买错了机房或线路只能重新下单。年付之前建议先买一台同线路的月付机型跑几天，把延迟、路由、磁盘 I/O 都测一遍再决定。

**3. 港台新是非原生 IP。** 洛杉矶是原生 IPv4。做站、跑 API、挂监控不受影响，但需要地区判定的服务会踩坑。

**4. “不限流量”不等于可以长期跑满端口。** 10Mbps 不限流量的意思是不按月计费流量，不是可以 7×24 小时占满 1.25MB/s 跑满一个月。公平使用政策和服务条款仍然管着，长期高位占用有被限速的可能。

**5. 这批套餐装不了 Windows。** Windows 系统要求至少 2GB 内存，年付机型只有 1GB，默认只能用 Linux 发行版。要 Windows 得往月付的高配机型走。

**6. 客服是工单制，主要用英文。** 响应一般在几个小时内，没有 7×24 在线客服，也没有明确的 SLA 承诺。遇到问题能解决，但不能指望它像国内厂商那样即时响应。

## 哪些人不适合买

需要中文实时客服的，工单加英文沟通会很别扭。需要 2GB 以上内存跑 WordPress 加插件、数据库或者 Docker 多容器的，1 核 1GB 会很快吃满，加钱上月付高配更省事。需要原生 IP 解锁流媒体又不想选洛杉矶机房的，港台新三地满足不了。对稳定性有合同级要求的生产业务，没有 SLA 承诺这一条就足够排除。

反过来，个人博客、静态站、API 后端、定时脚本、监控探针、开发测试环境、备用跳板，这类负载对内存和带宽要求不高，$24.99 一年的成本很难找到更低的替代。

## 常见问题

**$24.99 是首年价还是续费价？**
这是当前的售价，续费价格官方没有公开说明。下单前在订单页确认续费金额，不要假设第二年同价。

**香港机房能解锁 Netflix 吗？**
大概率不能。香港、台湾、新加坡都是非原生 IP，按 IP 判定地区的流媒体服务可能识别失败。要解锁就选洛杉矶，那里配的是原生 IPv4。

**能升级 CPU、内存、硬盘吗？**
$24.99 特价年付不支持升级，也不支持降级，配置买定离手。常规月付的弹性云可以升级。

**不满意能退款吗？**
特价年付不支持退款。这是这批套餐最需要注意的一条，建议先用月付机型验证线路再上年付。

**支持支付宝吗？**
支持。支付宝、PayPal、信用卡都能付款，部分渠道还接受加密货币。

**1 核 1GB 能跑什么？**
静态站点、轻量 WordPress、API 服务、爬虫、监控探针、开发测试环境都没问题。带数据库的中型站点或者并发稍高的应用，1GB 内存会先成为瓶颈。
